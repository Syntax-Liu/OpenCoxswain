# 控件规范（对话区）

> 2026-11-13 制定，对应 v0.55.0
> 基准：**VS Code**。控件紧凑、圆角小、无多余装饰。

---

## 零、为什么要有这份文档

用户反馈"UI 很别扭，别扭的地方特别多"。

**盘点后找到了量化证据**——同一屏里：

| 属性 | 实际用到 | 问题 |
| --- | --- | --- |
| 圆角 | 0 / 2 / 3 / 4 / 6 / 10 / 12px + 50% | **8 种尺度** |
| 字号 | 11 / 11.5 / 12 / 12.5 / 13 / 14 / 15px | **7 种**，还有半像素 |

**这不是审美问题，是没有尺度。** 每个控件被单独调过，互不参照。

这份文档定死**所有尺度**。以后改界面只许用这里的值。

---

## 一、尺度表

### 字号（4 档，不许中间值）

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `--fs-xs` | **11px** | 角标、时间戳、极简辅助文字 |
| `--fs-sm` | **12px** | 次要信息、行内代码、按钮小字 |
| `--fs-md` | **13px** | **正文默认**、按钮、输入框、列表项 |
| `--fs-lg` | **15px** | 标题（对话头 h2、面板头） |

**删除 11.5px 和 12.5px**——半像素字号在任何屏幕上都会模糊。

### 圆角（3 档）

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `--r-sm` | **3px** | 按钮、标签、输入框、行内代码 |
| `--r-md` | **4px** | 面板、卡片、浮层 |
| `--r-full` | **50%** | 圆形图标按钮 |

**对话气泡从 12px 改成 4px**——VS Code 里没有大圆角的容器，
12px 圆角在紧凑布局里显得"软"，与工具软件的调性冲突。

### 控件高度（3 档）

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `--h-sm` | **22px** | 小按钮、标签、图标按钮 |
| `--h-md` | **26px** | 标准按钮、输入框、tab |
| `--h-lg` | **32px** | 主操作按钮、发送按钮 |

### 间距（4px 网格）

| Token | 值 |
| --- | --- |
| `--g-1` | 4px |
| `--g-2` | 8px |
| `--g-3` | 12px |
| `--g-4` | 16px |
| `--g-5` | 24px |

**所有 padding / margin / gap 必须是 4 的倍数**（徽标内部等极小值除外，用 2px）。

## 二、控件清单

### 1. 按钮

| 变体 | 高度 | 圆角 | padding | 字号 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `.btn-primary` | 26px | 3px | 0 12px | 13px | 主要动作（发送、批准） |
| `.btn` | 26px | 3px | 0 12px | 13px | 标准按钮 |
| `.btn-sm` | 22px | 3px | 0 8px | 12px | 次要动作（用模板、停止） |
| `.link` | 16px | 3px | 0 | 12px | 文字链接（重试、复制） |

**状态**：

| 状态 | 变化 |
| --- | --- |
| hover | 背景提亮一档 |
| active | 背景再提亮 |
| focus-visible | 2px 外描边（用 accent 色，不改变布局） |
| disabled | 透明度 0.4 + `cursor: not-allowed` |

### 2. 输入框

| 项 | 值 |
| --- | --- |
| 高度（单行） | 26px |
| 圆角 | 3px |
| padding | 0 8px |
| 字号 | 13px |
| 边框 | 1px solid `--border` |
| focus | 边框改成 accent 色 |

### 3. 消息气泡

| 项 | 值 |
| --- | --- |
| 圆角 | **4px**（原 12px） |
| padding | 8px 12px |
| 字号 | 13px |
| 最大宽度 | 70% |
| 行高 | 1.5 |

### 4. 浮层 / 提示条

| 项 | 值 |
| --- | --- |
| 圆角 | 4px |
| padding | 8px 12px |
| 阴影 | 0 2px 8px rgba(0,0,0,.3) |
| 位置 | 贴住触发元素，间距 4px |

### 5. 状态栏 / 信息条

| 项 | 值 |
| --- | --- |
| 高度 | 22px |
| 字号 | 11px |
| padding | 0 12px |
| 分隔 | 4px gap，不用竖线 |

## 三、现存偏差清单

按"改完立刻有感"排序：

| # | 问题 | 现在 | 应改成 |
| --- | --- | --- | --- |
| 1 | 气泡圆角 | 12px | 4px |
| 2 | 半像素字号 | 11.5 / 12.5px | 12px |
| 3 | 按钮高度不一 | 23 / 26 / 32px 混用 | 22 / 26 / 32 三档 |
| 4 | 圆角 6 种 | 0/2/3/4/6/10/12 | 0/3/4 三档 |
| 5 | tab 字号 | 14px | 13px |
| 6 | 面板 padding 不齐 | 10px 12px / 5px 16px / 12px 24px | 统一 12px 16px |

## 四、执行方式

1. 先把尺度 token 加进 `:root`
2. 逐条按"现存偏差清单"改
3. **每改一批，抓真实截图给用户确认**
4. 用计算样式对比验证没有意外副作用

**不做的事**：不加新颜色、不加阴影层次、不改布局结构。
这一版只统一尺度。
