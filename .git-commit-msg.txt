feat: 自研四层结构运行时（v0.2.0）

按用户设想将产品从「dsh 插件」改为完全自研，不依赖任何外部 Agent 框架。

四层结构：A 用户 / B 全局助理 / C 项目助理 / D 执行者。

## 新增

- apps/runtime：自研运行时（产品本体）
  - C 一项目一常驻会话，关掉软件再打开带着原对话继续
  - C 派 D 并行，区分只读/读写/未声明写域
  - 连发不打断（next / step 双队列）
  - 先完成先汇报，同一批去抖合并
  - 卡点三分类（可自行重试 / 环境问题 / 需用户决定）
  - D 可续聊（带原上下文），C 知情
  - SQLite 持久化（node:sqlite，schema v4 + 迁移）
  - HTTP/SSE 服务层，断线可重放，静态资源带 ETag
  - 记忆层：本地 Markdown，写入有门槛
  - 运行指标（轮次/步数/token/吞吐/缓存/上下文），不做计费
  - 用量止损线（token 阈值，超限真停）
  - 危险动作审批（五类不可逆动作执行前拦下）
- apps/web：工作台界面（左侧导航：文件夹=C，条目=D）
- apps/shell：Tauri 2 桌面壳，自带 Node 运行时
- build-app.cmd / build-app.ps1：一键出包
- scripts/version.mjs：版本号单一来源，自动同步到 6 处
- docs/roadmap.md：后续发展方向

## 修复的真实缺陷

- 只读任务被当作「未声明写域」导致并行失效
- Tauri verbatim 路径导致 EISDIR，应用起不来
- 静态资源长缓存导致升级后仍加载旧界面
- 盘符根归一化成 "d:" 导致路径解析失败
- run_command 在 cmd.exe 下却建议 PowerShell 命令
- 执行者结算通知泄漏进用户对话流
